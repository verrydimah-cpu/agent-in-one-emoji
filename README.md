My AI agent in one emoji: the octopus. Eight arms working at once — searching, building, checking and watching in parallel — which is exactly how the agent behaves: many tools in motion on a single task, coordinated by one mind. The program writes that single glyph, and nothing else, to `entry.txt`.

## Run it

```sh
node main.ts
```

This writes the emoji to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that environment variable is set).
